# Cabeceira

Interpretador de análise de solo e ferramenta de custos: calagem, gessagem e adubação pelo Boletim 100 (IAC, 2022) para cana, soja, milho e sorgo; leitura de laudo em PDF; operações mecanizadas e custo do ciclo.

Abra pelo link do GitHub Pages e use "Adicionar à tela inicial" (iPhone) ou "Instalar app" (Android). Funciona sem internet depois de aberto uma vez. Os dados ficam só no aparelho de quem usa.

Esta pasta contém só o app pronto (build do PWA). O código-fonte fica fora deste repositório.
